# لعبة اصطياد القطط (Catch the Cats)

لعبة تفاعلية ممتعة حيث يتحكم اللاعب في شخصية لاصطياد القطط وجمع النقاط قبل انتهاء الوقت.

## كيفية اللعب

1. استخدم مفاتيح الأسهم على لوحة المفاتيح للتحرك:
   - سهم لأعلى: التحرك للأعلى
   - سهم لأسفل: التحرك للأسفل
   - سهم لليسار: التحرك لليسار
   - سهم لليمين: التحرك لليمين

2. حاول اصطياد أكبر عدد ممكن من القطط قبل انتهاء الوقت.

3. كل قطة تصطادها تضيف 10 نقاط إلى رصيدك.

4. اللعبة تنتهي عندما ينتهي الوقت (60 ثانية).

## المميزات

- تصميم جميل وجذاب
- سهولة الاستخدام
- عدادات للنقاط والوقت
- أصوت تفاعلية عند اصطياد القطط
- تصميم متجاوب يعمل على مختلف الأجهزة

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (Vanilla)
- Canvas API

## التثبيت

1. قم بتنزيل جميع الملفات في مجلد واحد
2. افتح ملف `index.html` في متصفح الويب
3. استمتع باللعبة!

## التطوير المستقبلي

- إضافة مستويات مختلفة
- إضافة أنواع مختلفة من القطط
- إضافة عوائق وتحديات إضافية
- إمكانية تخصيص الشخصية
- نظام حفظ النتائج
